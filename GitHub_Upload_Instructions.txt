### الخطوة 1: إنشاء Repository على GitHub

1. اذهب إلى: https://github.com/new

2. املأ المعلومات:
   • Repository name: udaplay-ai-agent
   • Description: AI Game Research Agent with RAG and Web Search
   • ✅ Public (أو Private حسب رغبتك)
   • ❌ لا تضف README أو .gitignore أو License

3. اضغط "Create repository"

### الخطوة 2: ربط المشروع المحلي بـ GitHub

افتح PowerShell في مجلد المشروع وشغل:

```powershell
cd "C:\Users\PC\Desktop\Market Research Agent Project"

# استبدل YOUR_USERNAME باسم المستخدم الخاص بك
git remote add origin https://github.com/YOUR_USERNAME/udaplay-ai-agent.git

# تأكد من الربط
git remote -v
```

### الخطوة 3: رفع المشروع

```powershell
# رفع الكود
git push -u origin master
```

إذا طلب منك تسجيل الدخول:
- Username: اسم المستخدم في GitHub
- Password: استخدم Personal Access Token (ليس كلمة المرور)

╔════════════════════════════════════════════════════════════════════════════╗
║  🔑 إنشاء Personal Access Token                                          ║
╚════════════════════════════════════════════════════════════════════════════╝

إذا لم يكن لديك Token:

1. اذهب إلى: https://github.com/settings/tokens

2. اضغط "Generate new token" → "Generate new token (classic)"

3. املأ المعلومات:
   • Note: "UdaPlay Project Upload"
   • Expiration: 90 days (أو حسب رغبتك)
   • ✅ repo (اختر جميع صلاحيات repo)

4. اضغط "Generate token"

5. انسخ الـ Token (لن تراه مرة أخرى!)

6. استخدمه كـ Password عند الـ push
