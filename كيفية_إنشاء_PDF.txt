╔════════════════════════════════════════════════════════════════════════════╗
║  🖨️ طريقة 1: تحويل HTML إلى PDF (الأسهل)                                ║
╚════════════════════════════════════════════════════════════════════════════╝

    1. افتح ملف HTML في Google Chrome أو Microsoft Edge
    
    2. اضغط Ctrl+P (أو File → Print)
    
    3. في خيارات الطباعة:
       • Destination: Save as PDF
       • Paper size: A4
       • Margins: Default
       • Scale: 100%
       • ✅ Background graphics (مهم!)
    
    4. اضغط Save
    
    5. كرر العملية للملف الثاني

╔════════════════════════════════════════════════════════════════════════════╗
║  🖨️ طريقة 2: استخدام Microsoft Edge (موصى بها)                         ║
╚════════════════════════════════════════════════════════════════════════════╝

    1. افتح الملف في Microsoft Edge
    
    2. اضغط على ... (More) → Print
    
    3. اختر "Save as PDF"
    
    4. تأكد من تفعيل "Background graphics"
    
    5. اضغط Save
